# React Custom Hook

This project is made using React.

## About

In this project I created a custom hook called `useFetch`.

The hook is used to get data from an API and show it in the React app.

## API Used

https://jsonplaceholder.typicode.com/users

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

npm install

4. Then run:

npm run dev

5. Open the local link shown in the terminal.

## Files

- `useFetch.js` - custom hook for fetching data
- `App.jsx` - displays the users
- `App.css` - basic styling
